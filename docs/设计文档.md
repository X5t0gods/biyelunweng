## 一、系统概述

### 1.1 项目背景

本系统面向中小型社区超市，提供**进销存 + 前台收银 + 会员营销 + 经营报表**一体化解决方案，支持门店日常运营管理的数字化需求。

### 1.2 设计目标

- **易用性**：简洁的 Web 界面，收银员可快速上手
- **完整性**：覆盖采购、销售、库存、会员、报表全流程
- **可靠性**：库存变动全程留痕，操作日志可追溯
- **灵活性**：支持 MySQL/SQLite 双数据库，适应不同部署环境

### 3.2 数据表关系说明

| 主表 | 从表 | 关系 | 说明 |
|------|------|------|------|
| User | PurchaseOrder | 1:N | 一个员工可创建多个采购单 |
| User | Sale | 1:N | 一个收银员可处理多个销售单 |
| User | OperationLog | 1:N | 一个用户有多条操作日志 |
| Category | Product | 1:N | 一个分类下有多个商品 |
| Supplier | Product | 1:N | 一个供应商可供应多个商品 |
| Product | StockLog | 1:N | 一个商品有多条库存流水 |
| Product | SaleItem | 1:N | 一个商品可出现在多个销售明细中 |
| PurchaseOrder | PurchaseItem | 1:N | 一个采购单包含多个明细 |
| Sale | SaleItem | 1:N | 一个销售单包含多个明细 |
| Sale | SaleReturn | 1:N | 一个销售单可关联多个退货单 |
| MemberLevel | Member | 1:N | 一个等级下有多个会员 |
| Member | Sale | 1:N | 一个会员可有多笔消费记录 |

### 3.3 核心字段设计说明

#### 3.3.1 库存管理

- **Product.stock**：当前库存数量，所有库存变动通过 `change_stock()` 方法统一处理
- **StockLog**：库存流水表，记录每次库存变动的类型、数量、变动前后库存、关联单号

#### 3.3.2 金额计算

- **Sale.total_amount**：应收金额 = 商品原价总和
- **Sale.discount_amount**：优惠金额 = 会员折扣产生的优惠
- **Sale.actual_amount**：实收金额 = 应收 - 优惠
- **Sale.cost_amount**：成本金额 = 商品进价 × 数量

#### 3.3.3 会员体系

- **MemberLevel.discount**：折扣率，0.95 表示 95 折
- **MemberLevel.point_rate**：积分倍率，消费 1 元获得 point_rate 积分
- **Member.points**：当前可用积分
- **Member.total_points**：累计积分（用于等级升级判断）
- **Member.balance**：储值余额

## 四、核心业务流程

### 4.1 采购入库流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  创建采购单  │────▶│  添加明细   │────▶│  确认入库   │────▶│  库存更新   │
│  (draft)    │     │  (商品/数量) │     │  (状态变更)  │     │  (流水生成)  │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
       │                   │                   │                   │
       ▼                   ▼                   ▼                   ▼
  ┌─────────┐        ┌─────────┐        ┌─────────┐        ┌─────────┐
  │生成单号 │        │计算小计 │        │校验状态 │        │调用     │
  │CG+时间戳│        │累计总额 │        │draft?   │        │change_  │
  │         │        │         │        │         │        │stock()  │
  └─────────┘        └─────────┘        └─────────┘        └─────────┘
                                                                  │
                                                                  ▼
                                                           ┌─────────────┐
                                                           │ StockLog    │
                                                           │ type=purchase│
                                                           │ qty=+N      │
                                                           └─────────────┘
```

**流程说明：**

1. **创建采购单**：填写供应商信息，系统自动生成采购单号（格式：CG+年月日+序号）
2. **添加明细**：选择商品、填写数量和单价，系统自动计算小计并更新采购总额
3. **确认入库**：校验采购单状态为 draft，遍历明细调用 `Product.change_stock()` 增加库存
4. **生成流水**：每次库存变动自动创建 StockLog 记录，类型为 purchase

### 4.2 POS 收银流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  商品检索   │────▶│  加入购物车  │────▶│  绑定会员   │────▶│  结算支付   │
│ (条码/名称) │     │  (Session)  │     │  (可选)     │     │             │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
       │                   │                   │                   │
       ▼                   ▼                   ▼                   ▼
  ┌─────────┐        ┌─────────┐        ┌─────────┐        ┌─────────────┐
  │查询商品 │        │库存校验 │        │查询等级 │        │生成销售单   │
  │校验状态 │        │数量累加 │        │计算折扣 │        │扣减库存     │
  │         │        │         │        │         │        │累计积分     │
  └─────────┘        └─────────┘        └─────────┘        └─────────────┘
                                                                  │
              ┌───────────────────────────────────────────────────┘
              ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                           结算事务处理                                  │
├─────────────────────────────────────────────────────────────────────────┤
│  1. 创建 Sale 记录（单号、金额、支付方式等）                            │
│  2. 创建 SaleItem 记录（商品快照、数量、单价、成本）                    │
│  3. 调用 Product.change_stock() 扣减库存（type=sale）                   │
│  4. 会员积分累加（points += actual × point_rate）                       │
│  5. 会员消费累计（total_spend += actual）                               │
│  6. 会员等级刷新（refresh_level）                                       │
│  7. 清空购物车                                                          │
│  8. 记录操作日志                                                        │
└─────────────────────────────────────────────────────────────────────────┘
```

**流程说明：**

1. **商品检索**：支持条码精确匹配或名称模糊匹配，仅检索在售商品
2. **加入购物车**：使用 Session 存储购物车，校验库存数量
3. **绑定会员**：通过卡号或手机号查询会员，自动应用等级折扣
4. **结算支付**：支持现金、微信、支付宝、银行卡、会员余额五种支付方式
5. **事务处理**：使用 `@transaction.atomic` 保证数据一致性

### 4.3 销售退货流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  选择原单   │────▶│  填写退货   │────▶│  退货处理   │────▶│  库存回补   │
│  (销售单号) │     │  (商品/数量) │     │  (生成退货单)│     │  (流水生成)  │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
       │                   │                   │                   │
       ▼                   ▼                   ▼                   ▼
  ┌─────────┐        ┌─────────┐        ┌─────────────┐     ┌─────────┐
  │校验状态 │        │数量校验 │        │生成退货单号 │     │调用     │
  │done?    │        │≤购买数量│        │记录退款金额 │     │change_  │
  │         │        │         │        │记录退货原因 │     │stock()  │
  └─────────┘        └─────────┘        └─────────────┘     └─────────┘
                                                                  │
              ┌───────────────────────────────────────────────────┘
              ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                           退货事务处理                                  │
├─────────────────────────────────────────────────────────────────────────┤
│  1. 创建 SaleReturn 记录（退货单号、原单、退款金额、原因）              │
│  2. 创建 SaleReturnItem 记录（退货商品、数量、退款单价）                │
│  3. 调用 Product.change_stock() 回补库存（type=return）                 │
│  4. 会员积分回退（按退款比例扣回）                                      │
│  5. 会员消费回退（total_spend -= 退款金额）                             │
│  6. 会员余额退还（如原支付方式为余额）                                  │
│  7. 会员等级刷新（refresh_level）                                       │
│  8. 更新原销售单状态为 returned                                         │
│  9. 记录操作日志                                                        │
└─────────────────────────────────────────────────────────────────────────┘
```

### 4.4 销售单作废流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  选择销售单 │────▶│  权限校验   │────▶│  库存回退   │────▶│  状态更新   │
│  (已完成)   │     │  (店长权限) │     │  (全量回退) │     │  (void)     │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
       │                   │                   │                   │
       ▼                   ▼                   ▼                   ▼
  ┌─────────┐        ┌─────────┐        ┌─────────────┐     ┌─────────┐
  │校验状态 │        │manager_ │        │遍历明细     │     │status=  │
  │done?    │        │required │        │全部回退库存 │     │void     │
```

### 4.5 库存变动统一入口

```
┌─────────────────────────────────────────────────────────────────────────┐
│                      Product.change_stock()                             │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│   调用场景                    变动类型              数量符号             │
│   ───────────────────────────────────────────────────────────────────   │
│   采购入库                    TYPE_PURCHASE         +N (正数)           │
│   销售出库                    TYPE_SALE             -N (负数)           │
│   退货入库                    TYPE_RETURN           +N (正数)           │
│   库存盘点                    TYPE_CHECK            ±N (可正可负)       │
│   报损                        TYPE_LOSS             -N (负数)           │
│   手动调整                    TYPE_MANUAL           ±N (可正可负)       │
│                                                                          │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│   处理逻辑：                                                            │
│   1. 记录变动前库存 stock_before = self.stock                          │
│   2. 计算变动后库存 self.stock = stock_before + quantity               │
│   3. 校验库存不为负                                                     │
│   4. 保存 Product 更新                                                  │
│   5. 创建 StockLog 记录（变动类型、数量、前后库存、关联单号、操作人）    │
│                                                                          │
└─────────────────────────────────────────────────────────────────────────┘
```
